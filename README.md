## STUDENT PLACEMENT MANAGEMENT SYSTEM

# About the Project

A Python and MySQL based project designed to manage student records, company details, job application and placement details.This project demonstrated database connectivity, CRUD operations and SQL queries using python.

# Technologies Used

- Programming language-Pyhton
- Database-MySQL
- Development tools- JupyterLab, MySQL Workbench

# Database Tables
- Student-Stores student details
- Company-Stores company details
- Application-Stores application status, student id and company detail
